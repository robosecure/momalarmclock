Set up Mom Alarm Clock on two iPhones

Before the first school morning, choose a quiet time to set up and test alarms and everyday reminders together.

iOS 26 supports iPhone 11 and newer, plus iPhone SE (2nd and 3rd generation). Both phones must be updated to iOS 26 or later. Check Apple’s compatible iPhone models.

  1. Start with both phones. Use two iPhones with iOS 26 or later on both, and install Mom Alarm Clock on each.
  2. Connect the intended devices. Follow the app’s current parent and child setup screens. Review permissions and reported alarm readiness, check that you are pairing the intended phones, and keep pairing codes private.
  3. Test an alarm and a reminder. Choose a parent-selected quiz, game, or printed QR alarm check. Test the complete alarm flow in both roles together, then try one everyday reminder. For printed QR checks, use the actual code supplied by the app.
  4. Read the result carefully. Check the reported date and status. A completed alarm check does not guarantee waking, and reported reminder activity is not proof a chore is finished. Check in directly when needed and keep a backup routine for important mornings.
