How a decision is recorded

  1. Review the exact item. Play the finished file and read the proposed action.
  2. Choose Approve or Reject / request changes. Rejection needs a specific change to make.
  3. Submit on GitHub. Sign in as robosecure, check the prefilled decision, then select Submit new issue.

Opening GitHub alone does not save a decision. Only a submitted decision from the owner account is accepted after its version, file hash and scope are checked. An agent-created review request is not an owner decision.

Feedback on GitHub is public. Keep private tester details out of it. Submission is not instant publication; receipt and the approved action must be confirmed separately.
