How to decide in chat

  1. Review the exact item. Play the file and read its complete proposed action.
  2. Copy a decision or feedback. Pending items offer exact decision controls. Approved and revision history offer “Feedback on this exact file” for suggested changes only.
  3. Paste into the Mom Alarm marketing chat. Copying alone does not send or record a decision. The exact file, version and scope must be verified before any action.

If clipboard access fails, the page shows selectable decision or feedback text for manual copy. GitHub issue submission remains an optional route under each pending item; opening its draft does not save a decision.

Keep private tester details out of public GitHub feedback. A decision is separate from publication, spending or execution.
